# Искусственный интеллект для информационной безопасности

Репозиторий содержит материалы курса и приложение «Ирис» на Python. Презентации, дополнительные материалы и расписание размещены рядом с каталогом проекта.

## Содержание

| Путь | Назначение |
| --- | --- |
| [Презентации](Презентации) | Презентации курса и сопровождающие файлы |
| [Дополнительные материалы](<Дополнительные материалы>) | HTML-материалы по темам курса |
| [Расписание.xlsx](Расписание.xlsx) | Расписание курса |
| [iris-project](iris-project) | Приложение определения видов ирисов, код, тесты и справочный набор |

## Получение материалов

```powershell
git clone https://github.com/tsenturion/iris.git
cd iris
```

Без Git выберите **Code → Download ZIP** на странице репозитория и распакуйте архив. Презентации и таблицу расписания открывайте подходящим приложением. HTML-материалы скачайте и откройте в браузере: просмотр файла на GitHub не заменяет отображение HTML-страницы.

## Запуск приложения «Ирис»

Установите Python 3.11 или новее. Из корня клонированного репозитория выполните:

```powershell
.\iris-project\start.ps1
```

Затем откройте <http://127.0.0.1:8501>. Скрипт подготовит окружение и модель; отдельное скачивание Iris не требуется. Для остановки нажмите `Ctrl+C` в терминале. Первая установка зависимостей требует доступа к Интернету.

Приложение определяет вид по измерениям одного цветка или CSV и ведёт журнал наблюдений. Предположение и подтверждённый человеком вид сохраняются отдельно от машинного прогноза. Сравнение моделей и группировка дают практический материал для модулей 1, 2, 5 и 6.

Полные инструкции по установке, использованию, командам, резервному копированию и решению проблем находятся в [README приложения](iris-project/README.md). Архитектура описана в [iris-project/docs/architecture.md](iris-project/docs/architecture.md), правила изменений — в [iris-project/CONTRIBUTING.md](iris-project/CONTRIBUTING.md). Лицензия приложения приведена в [iris-project/LICENSE](iris-project/LICENSE); источник и условия использования Iris — в [описании набора](iris-project/data/datasets/README.md).

## Обновление

В корне репозитория выполните `git pull --ff-only`. Перед обновлением работающего приложения остановите его и сохраните актуальную резервную копию пользовательского журнала по инструкции приложения.

## Проверка приложения

[GitHub Actions](https://github.com/tsenturion/iris/actions/workflows/check.yml) проверяет подготовку приложения и ключевые сценарии на Windows с Python 3.13. Команды выполняются внутри `iris-project`. Изменения только материалов курса не запускают проверку приложения.

Пользовательская база, обученные модели, логи, окружения, временные файлы Office и служебные инструкции исключены из Git.
