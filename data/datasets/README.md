# Справочный набор Iris

Источник включённых измерений: [scikit-learn/iris на Hugging Face](https://huggingface.co/datasets/scikit-learn/iris). Карточка источника указывает лицензию **CC0-1.0**; описание условий — [Creative Commons CC0](https://creativecommons.org/publicdomain/zero/1.0/).

| Файл | Назначение |
| --- | --- |
| `Iris.source.csv` | Сохранённый исходный файл источника |
| `iris.csv` | Нормализованный формат для приложения |
| `source.json` | Ссылки, дата получения, признаки и описание преобразования |

В наборе 150 строк, по 50 каждого вида. Четыре числовых признака описывают длину и ширину чашелистика и лепестка в сантиметрах. Названия столбцов приведены к формату проекта, у видов удалён префикс `Iris-`. Значения измерений и номера сохранены в версии источника; набор автоматически не заменяется встроенным Iris из scikit-learn.

`source_id` нужен для аудита обучающих и тестовых строк, в признаки модели он не входит. Пользовательские наблюдения и определения хранятся отдельно и не попадают в обучение автоматически.
