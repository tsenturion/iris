# Архитектура приложения «Ирис»

## Состав

| Компонент | Ответственность |
| --- | --- |
| `domain.py` | Измерения, наблюдения, виды, редакции и прогнозы |
| `dataset.py` | Проверка локального справочного Iris |
| `repository.py` | SQLite, редакции, прогнозы, транзакции и резервная копия |
| `service.py` | Сохранение наблюдений и экспорт журнала |
| `training.py` | Общее разбиение, обучение, подбор и подробная оценка |
| `models.py` | Метаданные, конвейеры, активация и применение моделей |

| `model_service.py` | Подготовка, обучение, сравнение, определение и сохранение |
| `batch.py` | Проверка CSV, формат пакетного результата и экспорт |
| `csv_tools.py` | Общая запись CSV в UTF-8 с BOM и экранирование формул |
| `ui.py` | Навигация, журнал, редактирование, сводка и карточка модели |

## Договорённости о данных

Порядок признаков фиксирован: `sepal_length_cm`, `sepal_width_cm`, `petal_length_cm`, `petal_width_cm`. Все значения — конечные положительные числа в сантиметрах. Метки видов: `setosa`, `versicolor`, `virginica`. Даты, номера, места, заметки и человеческие определения не входят в вектор признаков.

Справочный набор и пользовательский журнал разделены. Предположение человека, подтверждённый человеком вид и прогноз модели — самостоятельные сущности. Для подтверждённого вида обязательно основание; сохранение машинного результата не заполняет человеческие поля.

## Хранение наблюдений

SQLite в режиме WAL хранит текущие записи в `samples`, полные неизменяемые снимки в `sample_revisions` и результаты моделей в `predictions`. Схема имеет версию через `PRAGMA user_version`; создание и обновление выполняются в транзакции.

Правка проверяет ожидаемую редакцию. Сохранение записи и её снимка атомарно. Номера сравниваются через `casefold()`, включая кириллицу; проверка выполняется после получения блокировки записи `BEGIN IMMEDIATE`. Пакет использует общий словарь существующих номеров, чтобы не перечитывать журнал для каждой строки.

Прогноз ссылается внешним ключом на пару `(sample_id, sample_version)`. Перед сохранением его измерения сверяются с постоянным снимком. Позднейшая правка наблюдения не меняет прогноз. Последним для образца считается последний сохранённый прогноз самой новой редакции, для которой есть результаты. Поэтому позднее сохранение результата старой редакции не скрывает прогноз новой.

Актуальность означает совпадение редакции прогноза и записи. Любая правка создаёт новую редакцию, даже если изменены только заметки или человеческое определение. В интерфейсе прежний результат сохраняется, и пользователь может выполнить новое определение.

`save_new_predictions()` проверяет входные записи и сохраняет образцы, снимки и прогнозы одной транзакцией. Любая ошибка откатывает весь пакет. Эту же операцию использует сохранение одного нового цветка с результатом.

`backup_bytes()` использует API `sqlite3.Connection.backup()`, а не копирование открытой базы. Получается самостоятельный согласованный SQLite-файл с учётом WAL. Временная копия удаляется после получения байтов.

## Подготовка и жизненный цикл модели

`ModelService.prepare()` сначала пытается загрузить активный конвейер и проверить его среду. Если он готов, выбор пользователя сохраняется без обучения. Если активного конвейера нет или он недоступен, выполняется сравнение трёх методов и активируется рекомендованная модель.

Обучение использует стратифицированное разбиение 120/30 с `random_state=42`. Для всех классификаторов применяются одинаковые строки. Логистическая регрессия и ближайшие соседи включают `StandardScaler` в `Pipeline`; дерево работает без него.

Подбор `GridSearchCV` использует пять стратифицированных разбиений только обучающей части, `f1_macro` и небольшие фиксированные сетки. Преобразования обучаются внутри каждой итерации. Рекомендация определяется до итогового теста; при равных средних значениях используется порядок: логистическая регрессия, ближайшие соседи, дерево.

Каждая сохранённая модель имеет отдельный идентификатор, конвейер и описание: признаки, классы, параметры, версии среды, строки обучения и теста, метрики и результаты подбора. Сначала сохраняются и проверяются файлы, затем атомарно заменяется указатель активной модели. Ошибка нового обучения не меняет предыдущий указатель.

Отчёты сравнения и группировки сохраняются отдельно через `ExperimentStore`. Сравнение само по себе не активирует модель; это отдельный выбор пользователя или флаг команды. Показатели теста не участвуют в рекомендации.

## Применение модели

`LoadedModel.predict_many()` проверяет все измерения и один раз вызывает `predict_proba()` для таблицы с фиксированным порядком признаков. Из классов сохранённого конвейера формируются оценки и выбранный вид. Все результаты пакета получают одну модель и общее время. `predict()` использует этот же путь для одного образца.

`ModelService.classify_csv()` сначала полностью разбирает файл, затем один раз загружает активную модель и применяет её ко всем строкам. Диапазоны справочного Iris используются только для предупреждений, значения не исправляются автоматически. Если справочный файл недоступен, готовый конвейер по-прежнему может определять вид, но проверка диапазонов отсутствует.

Входной CSV ограничен 2 МБ и 5000 строками. Проверяются кодировка, заголовок, число значений, числа, даты, длины текста и повторные номера. Для неверных строк собираются ошибки с физическими номерами строк файла. Неверный набор не передаётся модели.

Результат определения находится в состоянии сеанса до явного сохранения. После сохранения интерфейс убирает повторную кнопку записи. Смена загруженного файла сбрасывает его прежний результат; при повторном определении одного цветка также сбрасывается отметка сохранения. В карточке всегда доступны измерения, использованные для результата.

Экспорт журнала сохраняет человеческие поля отдельно от последнего прогноза и указывает его редакцию и актуальность. CSV с результатами содержит вид, оценки, модель, алгоритм, время и замечания. Оба экспорта используют общее экранирование потенциальных формул в текстовых ячейках.

## Группировка без учителя

K-means обучается на четырёх масштабированных измерениях всех 150 справочных образцов без видов. Метки используются после обучения для ARI. Силуэт вычисляется в масштабированном пространстве, центры возвращаются в сантиметры. Отчёт содержит строки, центры и показатели; конвейер группировки не становится классификатором видов.

## Окружение и диагностика

Зависимости закреплены в `uv.lock`; `requirements.txt` экспортирован из него для запуска без `uv`. `start.ps1` работает из любой текущей папки, не загружает Python или датасет и сохраняет готовый активный классификатор.

По умолчанию данные и логи находятся рядом с проектом; предусмотрены `IRIS_DATA_DIR` и `IRIS_LOG_DIR`. Диагностика содержит операции хранения, подготовку и применение моделей, результаты проверки CSV и причины сбоев. Логи сохраняются до 30 дней, время — UTC. Интерфейс отображает время по Екатеринбургу.

Проверки хранения, команд и интерфейса используют временные папки. Полный сценарий кейса охватывает первое обучение, определение цветка, сохранение, подтверждение человеком, новую редакцию, обновление прогноза, CSV и резервную копию.
